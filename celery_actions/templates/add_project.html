About Project role id

Roles to semantically divide groups. They must exist in the database, created by the admin. Examples are: ['tech-inno', 'abc', 'CGND', '123', 'kco', 'ucanpv']

About Emails

E-mails will get an nygenome.org appended unless it is an external email. External emails can be used, but make sure they have already been added by an administrator. Press Create emails to add emails from the textarea.

Classes for project

About Classes

Projects have classes that relate to tissue types, cell types, or other meaningful biological taxonomy. Add classes by writing them in the textarea separated by your separator of choice and clic on Create classes to add them. Classes can't contain non-alphanumeric symbols or spaces.

About Additional information

If there's additional values you want to input such as being a visium project or an immunoflurescence project add it here: for visium projects the "isVisium" boolean is required to be true. For IF the "isIF" boolean set to true is required.

What happens when I submit?

If everything is filled correctly and the token is valid then we will sen an automatic request to GCP to create this project. Emails may not be required but to access this project you need to add the corresponding emails.
