Name of the project in Celery

Roles to store data accordingly and semantically divide groups. They must exist in the database, created by the admin. Examples are: ['tech-inno', 'abc', 'CGND', '123', 'kco', 'ucanpv']

Here we will list the specified directory in search for the samples to upload. Click on "add to selected" to add the samples you wish to upload. An individual menu per sample will appear below.

In the individual sample menus you can select to upload an image, spaceranger data, and selected genes for their expression to be visualized in Celery.

Use the third box to specify the full path to the location of the images, write one per line, they should match the selected images in the second box.

Write gene names, either separated by commas, or as a list, one per line. These genes will be available for visualization in Celery. This is only available for Visium

You may want to limit the list to around 80. If it becomes a large file, Celery will not be able to upload it, the maximum size is 30mb, which depends on the expression itself, which is why there's not a limited number of allowed genes

For Celery to be able to read the genes we need a "tissue_positions.csv" (or a legacy "tissue_positions_list.csv" file and a "filtered_feature_bc_matrix.h5" file which can be searched for in each sample box below.
